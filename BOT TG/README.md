# BOT TG

Telegram Bot MVP for lead notifications from website forms.

## MVP Flow

Website Form
↓
POST /api/leads
↓
Backend API
↓
Database
↓
Telegram Bot API
↓
Owner receives notification

## Planned Features

- Lead notifications
- Lead statuses
- Employee assignments
- Photo reports
- KPI tracking
- CRM integration

## Stack

- Node.js
- NestJS
- PostgreSQL
- Prisma
- Telegraf.js
- Redis
- Docker
