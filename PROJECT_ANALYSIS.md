# Анализ проекта VoltEdge

## Назначение

Проект - статический лендинг для услуги электромонтажа под ключ. Основная задача страницы: быстро объяснить инженерный подход, показать доверие через кейсы и гарантии, дать пользователю предварительный расчет и довести его до заявки.

## Выполненные задачи

- Собрана структура полноценного лендинга: hero, trust-strip, проблема, преимущества, услуги, кейсы, процесс, гарантии, отзывы, калькулятор, FAQ, финальная заявка, footer.
- Подключены внешние изображения Unsplash и иконки Lucide.
- Реализован адаптивный layout для desktop/tablet/mobile.
- Добавлена система scroll reveal и hover/click анимаций.
- Реализован калькулятор сметы с расчетом стоимости, summary и hidden payload для формы.
- Сделана визуальная CSS-модель дома, которая меняет состояние от выбранных опций.
- Добавлена локальная редакт-панель с авторизацией, настройками контента, стиля, анимаций, экспортом/импортом JSON и сменой пароля в `localStorage`.
- Проект перенесен в рабочую папку `C:\Users\user\Documents\Electro` и подготовлен под Git.

## UI/UX анализ

Сильные стороны:

- Первый экран ясно продает услугу и сразу дает два действия: расчет и просмотр кейсов.
- Визуальный стиль соответствует теме: темная инженерная эстетика, electric blue, оранжевый акцент, техническая типографика.
- Калькулятор - главный интерактивный актив лендинга: он повышает вовлечение и дает понятный следующий шаг.
- Навигация покрывает ключевые пользовательские вопросы: услуги, кейсы, калькулятор, процесс, гарантии, FAQ.
- Mobile-адаптация работает без горизонтального переполнения.

Риски и улучшения:

- Форма пока не отправляет данные на backend/CRM, а только готовит payload на клиенте.
- Telegram и WhatsApp сейчас имеют `href="#"`; для продакшена нужны реальные ссылки.
- Редакт-панель и демо-пароль находятся на клиенте. Это удобно для прототипа, но не является безопасной админкой для публичного сайта.
- Внешние CDN и Unsplash зависят от сети; для стабильного продакшена лучше локализовать критичные ассеты.
- Контенту можно добавить больше локального доверия: реальные фото объектов, районы Алматы, лицензии/допуски, условия гарантии.

## Проверки

- JS-синтаксис проверен через `node --check script.js`.
- Страница открыта через локальный сервер `http://127.0.0.1:4173/`.
- В браузере проверены загрузка, hero, калькулятор, форма заявки и консоль.
- Desktop/mobile проверка показала отсутствие горизонтального overflow.
- Исправлен 404 на favicon через встроенный SVG favicon.
- Усилены DOM-обновления в JS: прямые обращения к части элементов заменены безопасными обновлениями.

## Архитектура редакт-панели

- Панель расширена поверх существующего `siteSettings` и не дублирует админку.
- Добавлена масштабируемая модель `blocks`: `blockId`, `blockType`, `title`, `subtitle`, `description`, `items`, `media`, `cta`, `settings`, `isVisible`, `order`.
- Источник правды для редактора формируется из реального DOM через `BLOCK_SCHEMA`, поэтому панель учитывает фактически существующие секции.
- Через вкладку `Блоки` редактируются hero, доверительный strip, проблема, преимущества, услуги, кейсы, этапы, гарантии, отзывы, калькулятор, FAQ, форма и footer.
- Для калькулятора добавлены отдельные настройки цен за м², коэффициентов, фиксированных стоимостей, подписей опций, текста результата и легенды модели дома.
- SEO-настройки вынесены в вкладку `Данные`: title, description, keywords, theme-color.
- Временный вход без пароля включен флагом `DEV_AUTH_BYPASS` в `script.js`; для production его нужно вернуть в `false`.
- Нижняя панель действий редактора закреплена, чтобы сохранение было доступно на длинных блоках.
- Форма заявки получает расчет при событии submit: площадь, выбранные опции, итог, breakdown, время расчета и источник.
