# VoltEdge Алматы

Лендинг для электромонтажных работ в Алматы и Алматинской области.

## Структура проекта

- `index.html` - разметка лендинга, SEO-мета, секции, форма заявки и редакт-панель.
- `styles.css` - визуальная система, адаптив, анимации, калькулятор и 3D-like дом на CSS.
- `script.js` - анимации, калькулятор сметы, форма заявки, настройки редакт-панели через `localStorage`.
- `landing-preview*.png`, `calculator-preview*.png` - контрольные превью проекта.

## Что уже реализовано

- Первый экран с оффером, телефоном, CTA и доверительными метриками.
- Блоки услуг, кейсов, процесса, гарантий, отзывов и FAQ.
- Интерактивный калькулятор с типом объекта, площадью, пакетом, опциями, сроком и живой стоимостью в тенге.
- Визуализация дома, реагирующая на выбранные опции калькулятора.
- Форма заявки с прикреплением расчетных данных.
- Скрытая редакт-панель для локальной настройки контента, цветов, изображений и анимаций.
- Адаптивная навигация: desktop-меню и mobile-бургер.

## Локальный запуск

Можно открыть `index.html` напрямую в браузере. Для проверки через локальный сервер:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:4173/`.
